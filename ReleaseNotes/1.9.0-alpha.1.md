# LyricsX 1.9.0-alpha.1

First experimental release from the SmallSquare fork, based on upstream `develop`
`3407687`. Thanks to the upstream maintainers for LyricsX and its ongoing development.

- Reduce menu-bar lyric rendering overhead on macOS 26+, with static paging and
  24/30/60/90/120 fps options (30 by default).
- Size desktop lyric windows to their content and remove hidden windows from the
  screen, addressing black full-screen previews in Mission Control.
- Add a compact playback card with artwork, transport controls and local-player
  seeking. Click the cover or track information to open the local player.
- Add a Bluetooth AVRCP phone source, including automatic source selection and
  isolated Bluetooth workers. No phone companion app is required.

**Download:** Apple Silicon, macOS 12+. Ad-hoc signed and not notarized; first launch
may be blocked by macOS. iCloud/App Group-dependent features are not supported by this
package. It shares settings with existing LyricsX installations: quit other copies
before opening it. Automatic updates are disabled.

**Known limits:** iPhone metadata, progress and lyric changes have been exercised;
other devices and older macOS versions remain unverified. Bluetooth artwork is still
unavailable in the tested setup, and AVRCP seeking is disabled. Reconnection may need
the phone's Bluetooth settings open. No external artwork lookup is used for phones.

Release builds and 299 automated checks passed. The separate menu-bar and desktop
fixes received manual playback/Mission Control checks; broader alpha testing is still
needed. See [alpha instructions](https://github.com/SmallSquare/LyricsX/blob/v1.9.0-alpha.1/Documentations/ForkAlpha.md).

这是 SmallSquare fork 的首个实验版本，基于上游 `develop` 的 `3407687`。
感谢上游维护者持续开发 LyricsX。

- 降低 macOS 26+ 菜单栏歌词渲染开销，提供静态分页及 24/30/60/90/120 fps 档位，默认 30。
- 桌面歌词窗口按内容大小显示，隐藏时移出屏幕，修复调度中心全屏预览黑屏问题。
- 增加紧凑音乐控制器，支持封面、播放控制及本地播放器进度调节；点击歌曲区域打开播放器。
- 增加蓝牙 AVRCP 手机来源和自动选择，将蓝牙操作隔离到后台进程，无需手机配套 App。

**安装：** Apple Silicon、macOS 12+。临时签名，未经公证，首次启动可能被系统拦截。
此包不支持需要 iCloud/App Group 授权配置的功能。与已有 LyricsX 共享设置，启动前请退出
其他副本；自动更新已关闭。

**已知限制：** 已验证 iPhone 歌曲信息、进度和切歌歌词同步；其他设备与旧 macOS 尚未实测。
蓝牙封面在已测环境仍不可用，进度条不支持拖动；重连可能需要打开手机蓝牙设置。
不会通过额外网络通路查询手机封面。

Release 构建及299项自动检查通过；独立菜单栏和桌面修复已做实际播放及调度中心复核，
完整 alpha 仍需更广泛试用。详见[试用说明](https://github.com/SmallSquare/LyricsX/blob/v1.9.0-alpha.1/Documentations/ForkAlpha.md)。
