# LyricsX 1.9.0-alpha.1

An experimental fork release with bug fixes and new features, based on upstream `develop` at `3407687`.
Thanks to the upstream maintainers for their continued work on LyricsX.

- Performance fix: Reduce menu-bar lyric rendering overhead on macOS 26+, with static paging and 24/30/60/90/120 fps options (30 by default).
- Bug fix: Size desktop lyric windows to their content and remove hidden windows from the screen, fixing black full-screen previews in Mission Control.
- Feature: Add a compact playback card with artwork, transport controls and local-player seeking. Click the cover or track information to open the player.
- Feature: Add a Bluetooth AVRCP phone source and automatic source selection, with Bluetooth operations isolated in background processes. No phone companion app is required.

**Installation:** Apple Silicon, macOS 12+. Ad-hoc signed and not notarized; macOS may block the first launch.

Fork 后做了部分bug fix并增加部分feature实验版本，基于上游 `develop` 的 `3407687`。
感谢上游维护者持续开发 LyricsX。

- Fix性能问题：降低 macOS 26+ 菜单栏歌词渲染开销，提供静态分页及 24/30/60/90/120 fps 档位，默认 30。

- Feature：增加紧凑音乐控制器，支持封面、播放控制及本地播放器进度调节；点击歌曲区域打开播放器。
- Feature：增加蓝牙 AVRCP 手机来源和自动选择，将蓝牙操作隔离到后台进程，无需手机配套 App。

**安装：** Apple Silicon、macOS 12+。临时签名，未经公证，首次启动可能被系统拦截。
